# hari-lari-legal

Two static pages (GitHub Pages, custom domain `legal.harilari.com`; DNS: CNAME `legal` to `mortythemartian.github.io` at GoDaddy) that the Google OAuth consent screen of the Google Cloud project
`hari-lari` needs: a homepage and a privacy policy.

- Homepage: https://legal.harilari.com/
- Privacy policy: https://legal.harilari.com/privacy.html

Used by `hari-lari-analytics` (the weekly report uploads to Google Drive as the owner).
When the website (`hari-lari-website`) has its own /privacy page, point the Branding page of the
consent screen there and retire this repository.
